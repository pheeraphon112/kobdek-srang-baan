🔗 เชื่อม GitHub กับ Cowork

ทำครั้งเดียว ใช้ได้ตลอด — ทำตามได้เลยทีละขั้น

⏱ ใช้เวลาประมาณ 5–10 นาที
ทำไมต้องทำ?
ตอนนี้ Claude อ่านและสร้างไฟล์ได้บนเครื่อง แต่ยังส่งขึ้น GitHub ไม่ได้ พอทำขั้นตอนนี้เสร็จ Claude จะ push code, สร้าง branch, commit แทนเราได้เลย
1
เปิด Terminal บน Mac
Terminal คือหน้าต่างพิมพ์คำสั่งสีดำ
🔍
กด Command (⌘) + Spacebar พิมพ์ว่า "Terminal" แล้วกด Enter
หรือหาใน Applications → Utilities → Terminal
Terminal
nueng@mac ~ % _
✅
เห็นหน้าต่างสีดำหรือสีเทา มีข้อความ % อยู่ข้างหน้า = พร้อมแล้ว
2
ติดตั้ง GitHub CLI
ตัวเชื่อมต่อระหว่าง Claude กับ GitHub
📋
Copy คำสั่งด้านล่าง → วางใน Terminal → กด Enter
คัดลอกแล้ววางใน Terminal
brew install gh
⚠️
ถ้าขึ้นว่า "command not found: brew" ให้บอก Claude ได้เลย จะช่วยติดตั้ง Homebrew ให้ก่อน
Terminal — กำลังติดตั้ง
nueng@mac ~ % brew install gh
==> Downloading gh...
==> Installing gh...
✓ gh installed successfully
✅
รอจนขึ้น % อีกครั้ง = ติดตั้งเสร็จแล้ว (อาจใช้เวลา 1-2 นาที)
3
Login GitHub
ยืนยันตัวตนครั้งเดียว จบ
📋
Copy แล้ววางใน Terminal กด Enter
คัดลอกแล้ววางใน Terminal
gh auth login

จะมีคำถามขึ้นมา ตอบตามนี้เลยครับ:

Terminal — ตอบคำถาม
? Where do you use GitHub?
→ เลือก GitHub.com (กด Enter)
 
? What is your preferred protocol?
→ เลือก HTTPS (กด Enter)
 
? How would you like to authenticate?
→ เลือก Login with a web browser (กด Enter)
 
! First copy your one-time code: XXXX-XXXX
Press Enter to open github.com...
🌐
Browser จะเปิดขึ้นมา → วาง code ที่ได้ → กด Authorize
กลับมาที่ Terminal จะขึ้น "Logged in as [ชื่อ GitHub]"
✅
เห็นข้อความ "Logged in as ..." = เชื่อมสำเร็จแล้ว!
4
ตั้งชื่อให้ Git รู้จักเรา
ทำครั้งเดียว เพื่อให้ commit มีชื่อถูกต้อง
📋
Copy ทีละบรรทัด แล้ววางใน Terminal กด Enter
บรรทัดที่ 1 — ชื่อ
git config --global user.name "Nueng"
บรรทัดที่ 2 — อีเมล
git config --global user.email "pipawakorn.p@gmail.com"
✅
ไม่มี error = เสร็จสมบูรณ์แล้ว!

🎉 เชื่อมสำเร็จ! Claude ทำให้ได้แล้ว
